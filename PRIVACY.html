FW Mem Guard privacy

The extension has no FW Mem Guard account, telemetry, automatic report upload or cloud comparison service. It processes selected files locally. In guided WSL mode, full Map/ELF inputs transfer through VS Code from WSL to the Windows UI host for validation and comparison.

Local reports displayed inside VS Code and the Output log can contain input paths and section information. This describes the on-screen diagnostic output, not the reduced JSON produced by Export Report for Sharing. Review diagnostic text before voluntarily sharing it. Firmware/source files are not requested automatically. Support email is sent using your own mail service. Public issues in the separate documentation repository are visible to everyone.

Export Report for Sharing opens an unsaved JSON snapshot of usage, limits and result/context. It excludes paths, filenames, symbols, section names, addresses and input hashes, but is not anonymized or signed. Review the unsaved editor tab before using Save As; no report file is created automatically. If you attach it to a support email or another service, the provider and recipient receive what you send under their own policies. Share only what your organization permits. The extension performs no automatic upload.

This static documentation site is hosted by GitHub Pages. GitHub's own hosting/access logging policies apply. The pages include no custom analytics, tracking scripts, third-party font requests or comparison-file upload form. Video, captions and images are served from this site; the video plays only when you start it. External Marketplace and GitHub links use those services when you follow them.
